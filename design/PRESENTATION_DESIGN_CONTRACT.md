# 닿지 않는 돌봄 본선 발표 디자인 계약

## 목적

심사위원이 한 장마다 하나의 판단만 따라가도록 한다. 화면은 장식보다 근거, 수치보다 정의, 결론보다 검증 순서를 앞세운다.

사용자가 제공한 `DESIGN-apple`의 순백 배경·시스템 글꼴·넓은 여백·절제된 조작 원칙을 출발점으로 삼되, 색은 대한민국 공공기관 발표에 익숙한 네이비·행동 블루·검증 틸로 통일했다. 같은 색 계약을 MVP와 발표자료가 함께 사용한다.

## 기준 화면

- 캔버스: 1600×900, 16:9
- 구조: 본편 17장 + 부록 12장, 총 29장
- 관객용 HTML에는 대본을 넣지 않는다.
- 각 장은 `주장 1개 + 그 주장을 지지하는 시각 1개 + 출처 1줄`을 원칙으로 한다.
- 발표 16번 장은 실제 관산동 MVP 화면을 중심으로 한다.

## 컬러

| 역할 | 값 | 사용 |
|---|---:|---|
| 공공 네이비 | `#0B2E59` | 제목, 핵심 구조, 마감 장 |
| 행동 블루 | `#0066CC` | 분석 흐름, 비교축 |
| 검증 틸 | `#0A7C78` | 확인됨, 다음 행동 |
| 주의 적색 | `#B6403A` | 한계, 중복 경고, 보류 |
| 본문 차콜 | `#1D2433` | 본문 |
| 보조 회색 | `#5E6B7A` | 정의, 단위, 기준일 |
| 바탕 | `#FFFFFF`, `#F5F7FA` | 순백과 옅은 회색만 사용 |

- 그라디언트, 글로우, 장식용 그림자 금지.
- 빨강은 오류·위험처럼 꼭 필요한 경우에만 제한적으로 사용.

## 타이포그래피

- 한국어 시스템 산세리프: Pretendard → Noto Sans KR → Apple SD Gothic Neo → Malgun Gothic.
- 제목 48px, 표지 68px, 본문 17~25px, 출처 12px.
- 큰 수치는 38~55px. 작은 수치라도 단위·기준일을 바로 곁에 둔다.
- 제목은 가능한 두 줄 안에 두고, 한 줄에 여러 주장을 병렬로 넣지 않는다.

## 레이아웃

- 기본 여백: 좌우 84px, 상단 62px, 하단 출처 영역 54px.
- 중첩 카드와 반복 카드 그리드를 피한다. 표, 열린 레일, 지도, 단일 차트를 우선한다.
- 슬라이드 왼쪽의 얇은 블루 기준선은 본편 흐름을 보조하되, 지도·차트보다 먼저 보이지 않도록 제한한다.
- 표지·마감 장만 강한 비대칭 분할을 사용한다.
- 부록은 본편과 같은 디자인 언어를 유지하되 `APPENDIX` 표식을 둔다.

## 데이터 표현

- 공식 사실, 팀 분석, 시나리오, 미확인을 문구로 구분한다.
- 퍼센트·명·세대·개소·행을 섞지 않는다.
- 상관은 인과로, 시나리오는 효과로, 후보 포함수는 선정확률로 표현하지 않는다.
- 지도는 44개 행정동 경계를 사용하고 개인 위치를 표시하지 않는다.
- 대리자료와 실제자료를 같은 색·문구로 뭉개지 않는다.

## 금지 문구와 안전 문구

- 금지: `확정 취약지`, `최적 입지`, `정책 효과`, `아무도 보지 않았다`, `최초·유일`.
- 권장: `현장 확인 대상`, `검증 순서`, `일반화 시나리오`, `저희가 확인한 공개자료에서는 찾지 못했다`.
- `2.9만`은 2026년 3월 추정치, `62개`는 서비스 목록, `1,972명`은 선별 조사대상으로만 표기한다.

## 상호작용·출력

- 좌우키, PageUp/Down, Home/End, 터치 스와이프, 전체화면, PDF 인쇄를 지원한다.
- `?slide=N`으로 특정 장을 열고 `?capture=1` 또는 `?presenter=1`에서는 조작부를 숨긴다.
- 인쇄는 1600×900 한 장씩 총 29쪽이어야 한다.
- 외부 라이브러리와 인터넷 없이도 지도·차트·캡처가 모두 표시돼야 한다.

## 검수 기준

- 29장 수와 17+12 구성이 맞다.
- 행주동 고정 결론, `상관 미계산`, 4단계 MVP, 빈 슬롯, 확정 파일럿 문구가 없다.
- DSS `ρ=.931`, 요소 제거 3/8 교체, 안정 핵심 3동이 데이터 파일에서 표시된다.
- 관산동 실제 캡처 4장이 로드된다.
- 1600×900, 모바일 축소, 200% 확대, 인쇄에서 넘침과 잘림이 없다.
- JS 데이터 계약 결과가 모두 `true`다.
