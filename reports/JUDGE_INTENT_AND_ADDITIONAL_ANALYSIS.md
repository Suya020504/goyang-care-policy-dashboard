## 2. 심사위원들의 공통 의도

세 심사위원은 새 예측모형을 요구한 것이 아니다. 공통 판단 질문은 다음과 같다.

> 이 지도가 자동 도입 결론이 아니라 어떤 행정 검증과 의사결정으로 이어지는가?

이를 네 가지로 풀면 다음과 같다.

1. **구성 타당성**: 실제 돌봄 대상자와 서비스가 아닌 대리지표로 무엇까지 말할 수 있는가?
2. **정책 추가성**: 기존 마을버스가 수행하지 못하는 이동을 DRT가 실제로 보완하는가?
3. **효과 식별**: 직선거리, 가정 시나리오, 실제 운영효과를 구분하고 있는가?
4. **행정 활용성**: 담당자가 후보지를 확정하는 것이 아니라 다음 조사·자료요청·대안 비교를 수행할 수 있는가?

## 3. 심사위원별 숨은 판단 질문

### 심사위원 1: 대리분석을 실제 자료로 어떻게 교정할 것인가

- 실제 고양온돌 대상자와 62개 서비스를 받으면 어떤 변수와 계산을 교체하는가?
- `rho=.93`인 구성요소를 각각 독립 증거처럼 두 번 가중한 것은 아닌가?
- DRT 전·후 개선이라고 부르는 값이 무엇이며 현재 데이터로 식별 가능한가?

### 심사위원 2: 새로운 모델보다 기존 결과의 정책 의미가 충분히 검증됐는가

- 마을버스의 경로·방향·시간대·목적지를 DRT가 중복하는가, 보완하는가?
- High-High, 후보, 비후보, 현행 DRT 지역을 정확히 구분하는가?
- 기술 설명이 많아져도 `수요와 이동이 함께 검증되지 않았다`는 한 메시지를 유지하는가?

### 심사위원 3: 현재 분석의 실제 이름과 확장 가능성이 정확한가

- 현재 결과는 통합돌봄 서비스 접근성인가, 의료시설 지리적 근접성인가?
- 복지관·경로당·실제 서비스로 목적지를 바꾸면 후보가 얼마나 교체되는가?
- 기존 DRT의 통근·신도시형 목적과 고령·돌봄형 검토 목적을 공식 운영자료와 대표지역으로 구분할 수 있는가?

## 5. 추가 보완 제안

### P0-1. 기준집합·용어·단위 버전 잠금

- **배점 연결**: 데이터 활용성 20, 정책 활용성 25, 분석 정확성 15
- **필요 데이터**: 현행 똑버스 4개 운영권역·연계거점·운영시간, 행정동/법정동 매핑, 기준일
- **분석**: 기존 3행정동 비교와 공식 4운영권역을 분리한다. 공식 GIS가 없으므로 중첩률·Precision은 재계산하지 않고 권역-법정동-행정동 교차표만 사용한다.
- **산출물**: `운영권역 ↔ 행정단위 ↔ 분석단위` 교정표 1개
- **과장 위험**: 운영권역을 행정동으로 동일시하거나 3동·4권역 결과를 섞어 정책 재현율로 표현
- **완료 조건**: 코드·보고서·MVP·발표의 지역 수·용어·기준일 일치
- **중단 조건**: GIS 운영경계를 확보하지 못하면 성능값을 삭제하고 정성 비교만 사용

### P0-2. 효과 주장 3단계 증거 사다리

1. **관찰값**: HIRA 의료시설까지 직선거리·면적격자 커버리지
2. **가정 시나리오**: 승차접근·승하차·대기·차량속도·우회계수를 공개한 일반화 이동시간
3. **관찰 효과**: 실제 요청·배차·픽업·도착·서비스 완료와 비교 기준선

- **배점 연결**: 공공 활용성 20, 정책 활용성 25, 분석 정확성 15
- **산출물**: 증거 사다리 + 후보별 시나리오 범위 + 파일럿 KPI 퍼널
- **과장 위험**: 시나리오를 실제 효과로 표현하거나 70세 이상 1인세대를 수혜자로 합산
- **완료 조건**: 모든 값에 분모·단위·기준일·가정·증거 단계 표시
- **중단 조건**: 필요한 가정이 없으면 전·후 수치 `계산 보류`

### P0-3. 마을버스 ‘존재’에서 ‘기능 중복·보완’으로 확장

- **배점 연결**: 공공 활용성 20, 정책 활용성 25
- **필요 데이터**: 노선ID·유형·경유정류소 순서·노선형상·상하행 첫막차·계획배차·기종점
- **방법**:
  - 후보지역과 마을버스 정류소 보행권 `300/400/500m` 민감도
  - 의료·복지 목적지 도달 노선 여부
  - 출발권역→목적지 방향성
  - 계획배차와 서비스 시간대 공백
- **산출물**: 후보별 `중복 / 보완 가능 / 확인 불가` 표와 GIS 2장
- **과장 위험**: 계획배차를 실제 대기시간으로 사용하거나 노선 존재만으로 공급 충분 판정
- **완료 조건**: 대상 노선 exact match와 방향·형상·시간대 완전성 확인
- **중단 조건**: 수집 결과가 `complete=false`이거나 변형노선 식별이 실패하면 중첩률 미발표

### P1-1. 목적지 계층 민감도 분석

- **배점 연결**: 데이터 활용성 20, 공공 활용성 20, 분석 정확성 15
- **공개 데이터 후보**:
  - 고양시 경로당 현재 공식 웹 **593건**, 공식 Excel **594행**(파일 내부 2026년 6월 기준)
  - 고양시 노인종합복지관 3곳
  - 확보한 노인복지시설 원자료 498행
- **방법**:
  1. 의료 목적지 기준모형
  2. DSS의 명시적 시설분산 항만 복지 목적지로 바꾸는 부분 치환
  3. CAG의 RI와 DSS 시설분산 항을 함께 바꾸는 완전 치환
  4. 경로당·복지관·노인돌봄 수행기관을 개별 또는 결합하고, 결합층은 레코드 동일가중과 목록 동일가중을 분리
- **비교**: Top8 Jaccard, 순위 교체, 관산·행주·대화의 거리·CAG 변화
- **현재 완료 범위**: 공식 경로당 원천 591행 중 유효좌표 585건, 복지관 3건, 돌봄 수행기관 10건을 분리해 44동×3계층 최근접거리·면적격자 접근성을 계산했다. 최신 594행은 570행 좌표완성·수동검토 7·미매칭 12로 분리했다. 의료 기준 외 11개 복지 치환 시나리오에서 Top8 Jaccard·교체·지역별 순위와 CAG를 계산했다.
- **누락 편향 감사**: 기준 후보 8동 5/118행(4.237%), 비후보 36동 19/476행(3.992%), 차이 +0.246%p·위험비 1.062·Fisher 양측 p=0.800. 후보군 과집중 신호는 관찰되지 않았지만 개별 동 누락은 남는다.
- **민감도 결과**: 11개 치환에서 최저 Jaccard `0.333`, 최대 `4/8동` 교체. 가좌·효자·고양·관산은 11/11 유지됐고 관산도 모든 치환 Top8에 포함됐다. 경로당 공개좌표 585건과 최신 목록 연결완성 570건을 각각 적용한 부분·완전 치환의 Top8 집합은 동일했다.
- **미완료 범위**: 실제 고양온돌 62개 서비스 제공위치·방문형 여부·운영시간·자격·수용량을 반영한 유효 목적지 분석과 생산모형 검증은 기관자료 확보 전 계산할 수 없다.
- **과장 위험**: 경로당·복지시설을 실제 62개 통합돌봄 서비스로 대체했다고 표현하거나, 공개 치환 스트레스 테스트를 새 생산 DSS로 채택
- **완료 조건**: 최신 목록-공개좌표 자동결합률과 좌표완성률 공개, 수동검토·미매칭 분리, 누락의 지역 편향 점검, 목적지 정의별 Top8·순위 변화 산출
- **중단 조건**: 누락이 후보지역에 집중되면 순위 비교 중단

### P1-2. 실제 62개 서비스의 ‘유효 목적지’ 계약

좌표만 받는 것으로는 부족하다. 다음 필드를 함께 받아야 한다.

- 서비스 유형·대상 자격
- 제공기관과 실제 제공장소
- 방문형/내방형
- 운영시간·예약방식
- 수용량·대기
- 무장애·휠체어·동행지원 조건

산출물은 `62개 점 지도`가 아니라 대상 유형별로 실제 이용 가능한 목적지 집합과 필드 확보율이다. 좌표만 확보되면 결과 이름은 `서비스 등록위치 근접성`으로 제한한다.

### P1-3. 대상자 데이터의 공개/보호 환경 분리

- 공개 MVP: 행정동 집계와 익명 공개 공급점만 사용
- 보호 분석환경: 최소수집·가명결합·역할기반 접근·보유기간·출력 제한 적용
- 원칙: 개인 취약정보·건강·장애·서비스 이력은 공개 지도와 GitHub에 저장하지 않음
- 완료 조건: 법적 근거·관리주체·접근자·보유기간·출력 제한 승인

### P1-4. 오프닝 부재 주장 범위 고정

`아무도 보지 않았다`는 심사위원이 권한 발표 훅이지만, 보편적 최초 주장으로 쓰지 않는다.

권장 문구:

> 고양시는 돌봄이 필요한 사람을 찾고 서비스를 준비했습니다. 그러나 저희가 확인한 공개자료에서는 대상 수요와 실제 이동 가능성을 함께 검증한 결과를 찾지 못했습니다.

선행자료 조사 범위·도메인·확인일을 각주로 남기지 못하면 `아무도·최초·유일` 표현을 삭제한다.

## 7. 하지 않을 것

- 현재 RI에서 정류장 페널티를 뺀 단순 `RI_after - RI_before`
- `개선 수혜 세대` 또는 실제 도달률 주장
- VIF가 낮다는 이유로 `rho=.93` 중복 위험 종료
- 마을버스 노선 표기만으로 `중복 없음` 또는 `공급 충분` 판정
- 대화동을 HH·후보지역으로 표기
- 2.9만 명을 실제 이용자, 62개를 물리적 거점으로 표기
- 경로당 웹 593건·Excel 594행을 실제 고양온돌 서비스로 대체

## 8. 분석 완료 게이트

- 원자료·처리 산출물의 파일 해시와 기준일을 저장한다.
- 모든 비교에 모집단·분모·단위·가정·중단조건을 둔다.
- 시나리오와 실제 효과를 화면·보고서·발표에서 서로 다른 상태로 표시한다.
- API 수집은 정확 매칭·미해결 목록·`complete` 상태를 남긴다.
- 실제 자료가 없으면 결과를 만들지 않고 필요한 입력을 제시한다.
- 디자인과 발표자료 수정은 위 데이터·기능 계약이 고정된 다음 진행한다.
