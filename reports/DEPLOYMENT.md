# 배포 기록

## 2026-08-10 - Vercel 초기 공개 배포

### 발생한 문제

첫 배포는 성공 로그와 URL을 반환했지만 루트 주소가 `404 NOT_FOUND`였습니다.

### 원인

Vercel의 무프레임워크 자동 감지가 저장소의 `public/` 폴더를 출력 디렉터리로 선택했습니다. 이 프로젝트의 실행 진입점 `index.html`은 저장소 루트에 있으므로, `public/`만 배포하면 사이트 진입점과 `src/`, `styles.css`가 누락됩니다.

### 해결

`vercel.json`에 다음 설정을 고정했습니다.

```json
{
  "framework": null,
  "outputDirectory": "."
}
```

재배포 후에는 고정 별칭의 HTTP 200, 제목, 4개 화면, 모바일 가로 넘침, 콘솔·페이지 오류를 다시 확인합니다.

### 재발 방지

- 배포 로그의 성공 여부만으로 완료 판정하지 않습니다.
- 고정 URL에 직접 HTTP 요청을 보냅니다.
- 배포 URL을 대상으로 브라우저 스모크 테스트를 다시 실행합니다.

## 2026-08-10 - 발표자료 경로 추가

- 관객 덱: `/presentation/index.html`
- 발표자 대본 화면: `/presenter/index.html`
- 관객 덱과 대본 번들은 분리되어 있으며, 발표자 화면만 `script-data.js`를 읽습니다.
- 로컬 오프라인 실행에서도 iframe이 폴더 목록을 열지 않도록 `presentation/index.html`을 명시합니다.
- Vercel `cleanUrls`는 `false`로 둡니다. `/presentation`으로 확장자를 제거하면 상대 CSS·JS 경로가 루트로 해석되어 화면이 깨집니다.
- 재배포 후 루트·관객 덱·발표자 화면 세 경로를 각각 HTTP 200과 실브라우저로 확인합니다.

## 2026-08-10 - 안내형 현장조사 흐름 전환

- 루트 `/`는 최초 배포 당시 행주동을 기본 사례로 한 6단계 안내형 화면이었습니다. 2026-08-12 피드백 대응판부터 관산동을 기본 검증 사례로 사용합니다.
- 기존 고밀도 대시보드는 `?view=analysis&stage=1`부터 `stage=4`까지 보존합니다.
- `?stage=...`만 있는 이전 주소는 자동으로 분석 상세로 해석해 기존 북마크를 유지합니다.
- `?demo=1`은 두 화면의 로컬 상태를 초기화하되 `view`, `step`, `stage`, `dong` 주소는 보존합니다.
- 44개 행정동 지도는 기본 검정 채움을 허용하지 않고 일반 동·후보 동·선택 동을 서로 다른 색으로 표시합니다.
- 공개 배포 후 루트·관객 덱·발표자 화면 HTTP 200, 안내 6단계·기존 4화면·발표자료 브라우저 회귀, 390px·320px·200% 확대 가로 넘침, 콘솔·페이지 오류 0건을 다시 확인합니다.

## 2026-08-12 - 피드백 대응 분석과 공공 API 연결

- 루트 기본 사례를 관산동으로 바꾸고, 높은 고령수요와 양호한 공개 공급신호의 상충을 실제 서비스 도달 검증 질문으로 전환했습니다.
- DSS 공급지표 상관·VIF·구성요소 제거, 관산·행주·대화 비교, 마을버스 정적 존재와 공식 계획 배차 후보 교차검증을 공개 분석계약에 추가했습니다.
- `/?admin=1`에 TAGO·경기도·주소 API 연결 도구를 추가했습니다. 이 쿼리는 인증이 아니라 도구 표시 조건입니다.
- 인증키는 탭 세션에만 저장하고, 호출은 허용목록 서버리스 함수를 거치며 캐시·로그·다운로드 결과에 키를 남기지 않습니다.
- 브라우저 오용 완화를 위해 동일 Origin을 확인하고 서버리스 인스턴스 기준 1분 120회로 제한합니다. 이는 전역 공유 쿼터나 관리자 인증이 아니므로 장기 운영 시 Vercel WAF·공유 제한기를 별도로 검토합니다.
- 배포 후 새 키로 연결 테스트, CSV 로컬 검사, 키 제외 JSON 저장을 확인합니다. 정적 서버에서는 `/api`가 실행되지 않습니다.

- 복지 원천 591행 중 유효좌표 585건과 최신 594행 중 좌표완성 570행을 분리합니다. 후보 8동 5/118행, 비후보 36동 19/476행의 좌표 미완성률도 함께 공개합니다.
- 의료 목적지를 공개 복지 목적지로 바꾼 11개 스트레스 테스트를 추가합니다. 관산동은 11/11에서 유지됐지만 후보집합은 최대 4/8이 교체되어, 실제 62개 서비스 위치를 받기 전에는 생산모델로 사용하지 않습니다.
- 발표 16장의 MVP 캡처는 `npm.cmd run capture:presentation-assets`로 현재 6단계 화면에서 다시 만들고, 이후 `npm.cmd run export:presentation`으로 29장 PNG·29쪽 PDF를 갱신합니다.
- 공개 저장소에는 인증키·개인정보·복지시설명·주소·전화와 버스 내부 결합 ID를 포함하지 않습니다.
- 배포 완료 판정은 단위·Python 분석·전체 브라우저·29장 레이아웃·PDF 내보내기 통과 후 고정 URL 네 경로를 다시 확인하는 것으로 합니다.
