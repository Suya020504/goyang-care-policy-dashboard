# 복지 목적지 데이터 준비도

기준일: 2026-08-13

## 판정

심사위원이 요구한 의료시설 중심 분석의 확장을 위해 고양시 공식 경로당·노인종합복지관 목록을 확인하고, 경기데이터드림 공개좌표를 결합한 공간 대리분석과 11개 복지 목적지 치환 민감도까지 만들었다. 최신 2026년 6월 목록과 경로당 좌표표의 기준일이 다르므로, 결합 상태·버전 민감도·잔여 검토를 분리한다.

| 자료 | 확인 결과 | 현재 사용 범위 |
|---|---:|---|
| 고양시 경로당 현재 웹 화면 | 593건 | 현재 표시 총계 |
| 공식 사전공표 Excel | 594행 | 해시를 고정한 44동 집계 |
| 경로당 공개좌표 | 원천 591행 중 유효 585건 | 2025-06-30 공간 대리값 |
| 노인종합복지관 | 3곳 | 2026-02-27 공개좌표 3/3 |
| 노인돌봄서비스 수행기관 | 10곳 | 2026-03-02 공개좌표 10/10, 고양온돌 62개와 별개 |

공식 웹과 Excel의 1건 차이는 숨기지 않는다. Excel 내부 제목은 `2026년 6월 기준`이며 실제 594행과 내부 총계가 일치했다.

## 품질 확인

- 594행 모두 공식 동명 44종과 2026-04-01 분석 행정동명에 매칭
- 시설명·주소 결측 0
- 시설명+주소 완전중복 0
- 동일 주소 초과행 7, 동일 시설명 초과행 2는 최신 목록-좌표 결합 QA 검토대상
- 공개 CSV·브라우저 데이터에는 전화·담당자·팩스를 포함하지 않음
- 관산동 16곳, 행주동 13곳, 대화동 23곳
- 관산동 경로당 공개좌표 대리값: 최근접 직선거리 중앙값 513.879m, 도보 15분 거리 안 면적격자 76.738%
- 최신 594행 ↔ 공개좌표 자동연결 575행(96.801%): exact 157·정규화 418, 수동검토 7·미매칭 12
- 자동연결 중 공식 좌표 결측 5행을 제외한 좌표완성 570/594행(95.960%)
- 공개 익명 포인트는 경로당 585·복지관 3·노인돌봄 수행기관 10 = 598개이며, 44동×3계층 접근성은 132행
- 최신 목록의 좌표 미완성은 후보 8동 5/118행(4.237%), 비후보 36동 19/476행(3.992%)이다. 차이 +0.246%p·위험비 1.062·Fisher 양측 p=0.800으로 후보군 과집중 신호는 관찰되지 않았지만, 개별 동 누락은 별도 확인한다.

이 수치는 시설 수일 뿐 운영시간·수용력·이용자격·실제 도달 가능성을 뜻하지 않는다. 경로당·복지관을 고양온돌 62개 서비스와 동일시하지 않는다.

## 목적지 정의 민감도 판정

의료 목적지 기준모형 외에 부분 치환과 완전 치환, 개별 계층과 결합 계층을 나눈 **11개 복지 치환 시나리오**를 계산했다.

- 기준 Top8 대비 Jaccard 최솟값: `0.333`
- 최대 후보 교체: `4/8동`
- 11/11 유지 안정 핵심: 가좌동·효자동·고양동·관산동
- 관산동 Top8 유지: `11/11`
- 경로당 585건 대 최신 목록 좌표완성 570건: 부분·완전 치환 모두 Top8 Jaccard `1.000`

따라서 목적지 정의를 바꿔도 유지되는 핵심과 교체되는 후보를 구분할 수는 있지만, 공개 대리층만으로 새 확정 순위나 생산 DSS를 만들 수는 없다. 경로당 585건·복지관 3곳·노인돌봄 수행기관 10곳은 실제 고양온돌 62개 서비스의 제공위치·이용자격·운영시간·수용량이 아니다.

## 좌표 결합 판정과 잔여조건

경기데이터드림 공개좌표로 1차 공간분석은 완료했다. 별도 Juso 주소검색·좌표제공 `confmKey`는 공개좌표 결측·최신 목록 잔여 레코드의 보완 수단이며, 1차 좌표 확보의 필수조건은 아니다.

주소검색→좌표검색, 체크포인트 재개, 오류만 재시도, 5초당 좌표요청 10회 제한, 복수·미일치·수동검토 분리까지 로컬 파이프라인은 준비했다. 실제 Juso API 호출은 하지 않았다.

1. 도로명주소 검색 결과의 `admCd`, `rnMgtSn`, `udrtYn`, `buldMnnm`, `buldSlno`를 확보한다.
2. 좌표제공 API의 `entX`, `entY`를 저장한다.
3. EPSG:5179에서 화면 좌표계로 변환하고 원본 좌표와 변환계보를 보존한다.
4. exact·정규화·수동검토·미매칭을 분리하고, 수동검토 전 fuzzy 후보를 자동 확정하지 않는다.
5. 좌표가 확보된 목적지만 접근성 대리분석에 사용하고 최신 목록 결합률을 함께 표시한다.
6. 실제 62개 서비스는 별도의 제공장소·방문형 여부·운영시간·자격·수용량을 받아 다시 계산한다.

세부 시나리오·Top8·지역별 순위는 [복지 목적지 정의 민감도](WELFARE_DESTINATION_SENSITIVITY.md)에 고정했다.
