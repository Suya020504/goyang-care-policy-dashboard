# 복지 목적지 데이터 준비도

기준일: 2026-08-13

## 판정

심사위원이 요구한 의료시설 중심 분석의 확장을 위해 고양시 공식 경로당·노인종합복지관 목록을 확인하고, 공개 가능한 행정동 집계까지 만들었다. 좌표가 없어 접근성 재계산은 아직 수행하지 않았다.

| 자료 | 확인 결과 | 현재 사용 범위 |
|---|---:|---|
| 고양시 경로당 현재 웹 화면 | 593건 | 현재 표시 총계 |
| 공식 사전공표 Excel | 594행 | 해시를 고정한 44동 집계 |
| 노인종합복지관 | 3곳 | 명칭·주소 목록 |
| 정확 좌표 | 0건 | 접근성 계산 보류 |

공식 웹과 Excel의 1건 차이는 숨기지 않는다. Excel 내부 제목은 `2026년 6월 기준`이며 실제 594행과 내부 총계가 일치했다.

## 품질 확인

- 594행 모두 공식 동명 44종과 2026-04-01 분석 행정동명에 매칭
- 시설명·주소 결측 0
- 시설명+주소 완전중복 0
- 동일 주소 초과행 7, 동일 시설명 초과행 2는 지오코딩 전 검토대상
- 공개 CSV·브라우저 데이터에는 전화·담당자·팩스를 포함하지 않음
- 관산동 16곳, 행주동 13곳, 대화동 23곳

이 수치는 시설 수일 뿐 운영시간·수용력·이용자격·실제 도달 가능성을 뜻하지 않는다. 경로당·복지관을 고양온돌 62개 서비스와 동일시하지 않는다.

## 좌표화 완료조건

TAGO 키와 별개인 Juso 주소검색·좌표제공 `confmKey`가 필요하다.

주소검색→좌표검색, 체크포인트 재개, 오류만 재시도, 5초당 좌표요청 10회 제한, 복수·미일치·수동검토 분리까지 로컬 파이프라인은 준비했다. 실제 공식 API 호출과 좌표 산출은 승인키 입력 전까지 수행하지 않았다.

1. 도로명주소 검색 결과의 `admCd`, `rnMgtSn`, `udrtYn`, `buldMnnm`, `buldSlno`를 확보한다.
2. 좌표제공 API의 `entX`, `entY`를 저장한다.
3. EPSG:5179에서 화면 좌표계로 변환하고 원본 좌표와 변환계보를 보존한다.
4. 자동 정확매칭률 95% 이상, 미매칭·복수후보 100% 수동검토 목록화를 완료한다.
5. 좌표가 확보된 목적지만 접근성 민감도 분석에 사용한다.
