# 닿지 않는 돌봄

고양시 교통·복지 담당자가 **현장조사를 먼저 검토할 행정동을 좁히고**, DRT·고정노선·바우처 택시·복지셔틀·방문서비스를 함께 비교하는 정책 사전검토 대시보드입니다.

이 저장소는 팀 `도달`의 2026년 고양시 빅데이터 공모전 본선 준비용 공개 MVP입니다. 고양시 공식 서비스가 아니며, 개인의 실제 돌봄 필요도·이동경로·서비스 이용기록을 사용하지 않습니다.

- 라이브 MVP: <https://goyang-care-policy-dashboard.vercel.app/>
- 관객용 HTML 발표자료: <https://goyang-care-policy-dashboard.vercel.app/presentation/index.html>
- 발표자 대본·대조 화면: <https://goyang-care-policy-dashboard.vercel.app/presenter/index.html>
- GitHub: <https://github.com/Suya020504/goyang-care-policy-dashboard>
- 분석 단위: 고양시 44개 행정동
- 기본 실행: 정적 HTML·오프라인 가능
- 데이터 보완 도구: `?admin=1`에서만 노출되는 세션 한정 공공 API 연결

## 무엇을 보여 주나

첫 화면은 공무원이 한 번에 한 질문만 읽도록 구성한 6단계 안내형 흐름입니다.

1. **서비스 설명** — `돌봄이 필요한 곳, 이동부터 확인합니다`라는 한 문장으로 문제·분석·행동을 설명하고 현장조사 범위를 고정
2. **관산동 신호** — 높은 고령수요와 양호한 버스·의료 대리신호가 충돌하는 이유를 확인
3. **근거 확실성** — 후보집합 8/8, 공급지표 순위상관 0.931, 구성요소·목적지 정의를 바꿨을 때의 후보 교체와 이동시간 가정 범위를 구분
4. **확인할 빈칸** — 확보/API 필요/기관협조를 나누고 실제 대상자·62개 서비스 위치·마을버스 배차·OD·운영자료를 체크
5. **대안별 조사** — 다섯 질문을 한 문항씩 확인하며 답변은 미확인·예·아니오로만 기록
6. **체크리스트 저장** — 인쇄·PDF를 기본 전달물로 만들고 개인정보 없는 JSON을 근거 백업으로 저장

기존의 고밀도 분석 화면은 우측 상단 **분석 상세**에서 별도로 엽니다. 분석 상세에는 현황 GIS, 후보 8곳 비교, 포스터 주장 29건 재검증, 민감도·공간통계, 다섯 정책 대안의 시연용 규칙이 보존되어 있습니다.

대시보드는 사업 도입지를 자동 결정하지 않습니다. 결과는 **우선검토 후보와 추가 데이터 요청 순서**를 돕는 공개데이터 대리진단입니다.

공식 목적지 보완에서는 관산동 경로당 `16곳`을 포함한 최신 파일 594행과 경기데이터드림의 유효 경로당 좌표 585건을 연결했습니다. 엄격 자동연결은 575/594행, 좌표완성은 570/594행이며 수동검토 7행·미매칭 12행을 따로 남겼습니다. 관산동의 최근접 직선거리 중앙값은 `514m`, 도보 15분 거리 안 면적격자는 `76.7%`입니다. 좌표 기준일은 2025-06-30으로 최신 목록보다 약 1년 앞서며, 이 값은 주민 도달률이나 실제 고양온돌 62개 서비스 이용 가능성이 아닙니다.

## 실행

`index.html`을 Chrome 또는 Edge로 열면 인터넷 없이 동작합니다. 정적 서버로 실행하려면 저장소 루트에서 다음 명령을 사용할 수 있습니다.

```powershell
python -m http.server 4173
```

그다음 <http://localhost:4173>을 엽니다.

### 공공 API 연결

배포 사이트의 `/?admin=1`에서 **데이터 연결**을 열 수 있습니다. 이 주소는 관리자 인증이 아니라 도구 표시 조건입니다.

- 인증키는 현재 탭의 `sessionStorage`에만 보관하며 탭을 닫으면 사라집니다.
- 키는 URL·`localStorage`·체크리스트·수집 JSON에 넣지 않습니다.
- 정류장 CSV는 브라우저 안에서만 읽고 서버로 업로드하지 않습니다.
- API 호출은 허용된 공식 호스트·작업·파라미터만 서버리스 중계합니다.
- 요청 보호는 서버리스 인스턴스 기준 1분 120회의 최선 노력형 제한입니다. 전역 사용자 인증이나 공유 쿼터는 아닙니다.
- 공개 대화나 저장소에 노출한 키는 폐기하고 새로 발급한 키를 입력해야 합니다.

### 발표자료

- 관객 화면: `presentation/index.html`
- 발표자 대본·대조 화면: `presenter/index.html`
- 특정 슬라이드 직접 열기: `presentation/index.html?slide=9`
- 발표자 화면 특정 슬라이드: `presenter/index.html?slide=16` (6단계 시연 큐)
- 현재 MVP 1~4단계 캡처 갱신: `npm.cmd run capture:presentation-assets`
- 로컬 PNG 29장·PDF 내보내기: `npm.cmd run export:presentation` (`presentation/export/`, Git 제외)

관객 화면은 29장 16:9 덱(본편 17장 + 질의응답용 부록 12장, A0~A11)입니다. 심사 피드백에 따라 관산동을 기본 사례로 두고, DSS 의존성, 마을버스 정적 스크리닝, 복지 목적지 준비도, 이동시간 가정표, 똑버스 권역 교정을 순서대로 설명합니다. 발표자 화면은 관객 슬라이드와 별도 대본을 나란히 보여 주며, 설명 670초·화면 전환 40초·MVP 시연 110초를 중복 없이 계산합니다. 관객용 `presentation/**`에는 대본 데이터가 포함되지 않습니다.

## 테스트

Node.js 20 이상에서 데이터 계약·정책 규칙·공개 배포 검사를 실행할 수 있습니다. 단위 테스트는 설치 없이 실행되고, 브라우저 검사용 `playwright-core`는 `npm install`로 준비합니다.

```powershell
npm.cmd test
npm.cmd run test:data-python
```

전문분석 산출물을 다시 만들려면 원자료를 덮어쓰지 않은 검증된 `2026-08-09_재현분석` 폴더를 별도로 준비하고 환경변수로 지정합니다. 공개 저장소에는 원자료·개인정보를 포함하지 않습니다.

```powershell
$env:DDOL_ANALYSIS_ROOT='검증된_재현분석_폴더의_절대경로'
python scripts/build_professional_analysis.py
node --test tests/pro-analysis.test.js
```

이 분석의 이동시간 값은 접근·승하차 5분, 대기 5·10·15분, 거리계수 1.3, 차내 15km/h, 환승 0회라는 공개 가정이다. 관측된 DRT 운영성과·개인 또는 가구 단위 결과·62개 돌봄서비스 도달률로 해석하지 않는다.

브라우저 검사는 Playwright가 준비된 환경에서 실행합니다.

```powershell
$env:PLAYWRIGHT_CHROMIUM_PATH='C:\Program Files\Google\Chrome\Application\chrome.exe'
npm.cmd run test:browser
```

발표자료만 확인하려면 다음 명령을 사용합니다.

```powershell
npm.cmd run test:presentation
npm.cmd run test:layout
```

## 공개판 GIS

초기 로컬 MVP의 고양시 생활지도 파생 경계는 공개 재배포 조건이 확인되지 않아 제외했습니다. 공개판은 제출 재현분석에 실제 사용한 `admdongkor` 2026-04-01 경계로 다시 생성했으며, SGIS와 `admdongkor`를 함께 출처표시합니다.

유지관리자가 검증된 원자료를 보유한 경우 다음 스크립트로 표시 경계를 다시 생성할 수 있습니다.

```powershell
python scripts/build_public_boundary.py `
  --boundary data/raw/admdongkor_HangJeongDong_ver20260401.geojson `
  --bus-stops data/processed/bus_stops.csv `
  --facilities data/processed/facilities.csv
```

원자료는 라이선스·용량·계보 분리를 위해 이 저장소에 포함하지 않습니다.

## 개인정보와 인증키

사용자 추적과 데이터베이스는 없습니다. 안내형 진행 상태는 브라우저의 `localStorage`에, 공공 API 인증키는 관리자 도구를 연 현재 탭의 `sessionStorage`에 분리해 저장합니다. API 요청 시 키는 공식 API 호출을 중계하는 서버리스 함수에 전달되지만 애플리케이션 코드는 이를 기록·영구 저장하지 않고 응답에서 제출키를 제거합니다. Vercel과 공식 API 사업자의 인프라 처리 정책은 각각의 약관을 따릅니다. 공용 PC에서는 개인정보를 입력하지 말고 시연 후 상태와 키를 삭제하세요. 자세한 내용은 [PRIVACY.md](PRIVACY.md)를 확인하세요.
